# G-AILAB AI Parking Companion

장애인 주차 **자동 인증** · 맞춤 복지혜택 · 체육/생활시설 예약 앱.
HTML 프로토타입(12화면)을 Flutter + Supabase로 재구현한 것.

핵심 가치는 **버튼 0개 인증**이다. 장애인주차면 반경에 들어오면 앱이 스스로 인증을 시작해
GPS 반경 확인 → 등록 차량 대조 → 단속 시스템(G.Eye-Parking) 전달까지 끝낸다.
그 인증·이용 이력이 맞춤 복지혜택 추천과 시설 예약으로 이어진다.

**최종 목표: Google Play · App Store 출시.**
거기까지 남은 일은 [출시까지 남은 일](#출시까지-남은-일)에 정리했다.

## 실행하기

### 키 없이 (목업 모드)

키가 하나도 없어도 **13개 화면이 전부 동작한다.** 목업 리포지토리가 프로토타입과 같은
데이터를 메모리로 제공한다. 위젯 테스트도 이 경로로 돈다.

```bash
cd app
flutter run
flutter test      # 25개
flutter analyze
```

### 실제 백엔드로

`config.example.json`을 `app/config.json`으로 복사해 값을 채운 뒤:

```bash
flutter run --dart-define-from-file=config.json
```

키가 비어 있는 항목은 자동으로 목업/비활성으로 남는다. 예를 들어 네이버 지도 키만 없으면
**지도만** 격자 목업이고 나머지는 실제 데이터로 돈다. 발급 절차는 [docs/SETUP.md](docs/SETUP.md).

### 스키마 올리기

Docker 없이, `supabase login` 없이 연결 문자열만으로 올린다.

```powershell
# 직접 연결(db.<ref>.supabase.co)은 IPv6 전용이라 DNS가 안 잡히는 환경이 있다.
# 그럴 땐 Session pooler 를 쓴다.
$u = 'postgresql://postgres.<ref>:<password>@aws-0-ap-northeast-1.pooler.supabase.com:5432/postgres'
npx supabase db push --db-url $u --include-seed
```

## 현재 개발된 것

### 화면 13개

프로토타입 12화면 + 로그인 화면(신설). 모두 실제 데이터로 동작한다.

| 화면 | 내용 |
|---|---|
| 로그인 | 카카오·네이버·구글 버튼 (디버그 빌드에는 개발용 계정 버튼) |
| 온보딩 3단계 | 복지카드 촬영 → 자격 정보 확인 → 차량·주차표지 등록, 끝나면 권한 요청 |
| 홈 | 인증 상태 히어로(대기/진행/완료), 통계 2×2, 오늘의 알림, 신고 진입 |
| 자동 인증 시트 | 라우트가 아닌 오버레이. 3단계 진행, "숨기기"해도 계속 진행 |
| 인증 확인증·이력 | 다크 확인증 카드 + 이력 목록(인증/미인증을 아이콘으로도 구분) |
| 주변 주차면 지도 | 지도 + 잔여면 핀 + 목록, 선택 시 "여기서 인증 실행" |
| 복지혜택 피드 | 적합도 링 게이지, 카테고리 필터, 매칭 근거 태그 |
| 혜택 상세·신청 | "이 혜택이 뜬 이유", 지원 내용 표, 신청 → 접수됨 |
| 시설 검색 | 이름·설명·태그 부분 일치 검색 + 카테고리 |
| 시설 예약 | 날짜·시간 슬롯, 목적지 주차면 확보 안내 |
| 내 예약 | 확정/대기 배지, 취소(확인 다이얼로그) |
| 마이페이지 | 자격 정보, 알림 토글 5개, 등록증 재인증 |
| 부정주차 신고 | 사진 업로드, 사유 라디오, 접수번호 발급, 내가 받은 경고 |

디자인 토큰(색·타이포·radius·그림자)은 프로토타입에서 [`tokens.dart`](app/lib/core/theme/tokens.dart)로
1:1 이식했다. 적합도 링(conic-gradient), iOS식 토글, blink/floaty 애니메이션도 직접 구현했다.

### 자동 인증 — 두 경로

```
앱 시작 → nearby_spots() 로 가까운 주차면 조회 (거리순, 최대 20개)
      ├─ OS 지오펜스 등록 (native_geofence)
      │    앱이 꺼져 있어도 발화. "항상 허용" 권한 + Supabase 설정 필요
      └─ 포그라운드 워처 (foreground_geofence.dart)
           앱이 떠 있을 때만. "사용 중" 권한으로 충분
                    ↓ 반경 진입
      start_certification() → DB 트리거가 차량 대조 후 즉시 verified
                    ↓
      Realtime 으로 앱이 받아 시트 표시 → 이탈하면 end_certification()
```

설계상 지키는 것:

- **시트를 닫아도 인증은 계속된다.** 표시 여부(`hidden`)와 인증 상태는 완전히 분리돼 있다.
- 두 경로가 동시에 인증을 시작해도 안전하다. `start_certification`이 진행 중인 세션을 그대로 돌려준다.
- **1km 이상 이동하면 주차면 목록을 다시 받는다.** 목록이 늦게 도착해도 마지막 위치로 즉시 재판정한다
  (차를 세운 뒤 목록이 오면 위치 이벤트가 더 안 와서 영영 감지 안 되던 문제).
- 위치가 "항상 허용"이 아니면 홈에 *"지금은 앱을 열어 둔 동안만 인증돼요"* 를 띄운다. 숨기지 않는다.
- **보내지 않은 것을 보냈다고 하지 않는다.** `certifications.transmitted`가 true일 때만 "전달됨",
  아니면 "연동 대기"로 표시한다. 이 규칙은 테스트로 고정돼 있다.

### 백엔드 (Supabase)

- `profiles` — 복지카드로 확인된 자격 정보. **촬영본은 저장하지 않는다**
- `vehicles` / `parking_spots` / `certifications` — 자동 인증
- `benefits` + `match_benefits()` — 적합도와 근거 태그를 **서버가** 계산
- `facilities` / `facility_slots` / `bookings` / `parking_holds` — 예약과 주차면 확보
- `reports` / `warnings` / `devices` — 신고, 경고, 푸시 토큰

RLS는 개인 데이터를 본인 행으로 제한한다. 잔여 슬롯·주차면 확보처럼 동시성이 걸리는 작업은
전부 RPC로 모아 한 트랜잭션으로 처리한다.

### 검증된 것

**실제 Supabase API로 확인:**

| 항목 | 결과 |
|---|---|
| `benefits_for_me` | 적합도 98/95/92/88/84/79 — 프로토타입과 정확히 일치 |
| `nearby_spots` | PostGIS 거리 계산, 거리순 정렬 |
| `book_facility_slot` / `cancel_booking` | 슬롯 2→1 + 주차면 4→3 동시 감소, 취소 시 완전 원복 |
| RLS | 익명 접근 0건 / 401, 로그인 시 본인 행만 |
| `submit_report` | 접수번호 발급 (`R-2026-0818-001`) |
| 자동 인증 | 진입 → `certifications` 생성 → 트리거가 verified 까지 |

**Android 에뮬레이터 + mock location으로 확인** (`docs/screenshots/`):
버튼을 하나도 누르지 않고 `반경 밖 → 진입 → 3단계 → 완료 → 이탈 → 대기 복귀` 전 구간.

**아직 검증 못 한 것:** 화면이 꺼지거나 앱이 종료된 상태의 **OS 지오펜스**. 실기기가 필요하다.

## 나중에 붙여야 할 백엔드

지금은 **앱이 돌아가는 데 필요한 최소한**만 서버에 있다. 아래는 실서비스로 가려면
반드시 붙여야 하는 것들이다. 우선순위 순.

### A. 출시를 막는 것 (blocking)

#### 1. G.Eye-Parking 단속 시스템 연동 🔴

이 앱의 존재 이유. 지금은 인증을 DB에만 기록하고 **단속 시스템에는 아무것도 보내지 않는다.**

- 지금: `certify-parking` Edge Function에 인터페이스만 잡혀 있음. `transmitted = false`
- 필요: 엔드포인트·인증 방식·요청/응답 스키마 확정 → 함수 배포 + Database Webhook 연결
- 연동 전까지 앱은 "연동 대기"로 표시한다. **이 상태로 출시하면 안 된다** —
  사용자가 인증됐다고 믿고 차를 두면 과태료를 맞는다

#### 2. 복지카드 실제 검증 🔴

- 지금: 온보딩이 자격 정보를 **확인만** 한다. 실제 검증 경로가 없어 누구나 "지체장애 2급"이라고 주장할 수 있다
- 필요: 보건복지부 장애인등록 확인 API 연동, 또는 OCR + 수동 심사 큐
- `verify-welfare-card` Edge Function은 아직 없다. 촬영본을 저장하지 않는 정책은 유지할 것

#### 3. 계정 삭제 경로 🔴

- 지금: 없음
- 필요: 앱 내 탈퇴 + 데이터 삭제 API. **Play·App Store 둘 다 필수 심사 항목**이다
- `auth.users` 삭제 시 cascade가 걸려 있으니 서버 함수 하나면 된다

#### 4. 주차면 실시간 잔여면 🔴

- 지금: 시드 고정값. **절대 변하지 않는다.** "3면 남음"이 거짓이 된다
- 필요: 공공 API 또는 G-AILAB 카메라 집계 → `parking_spots.available` 갱신 잡

#### 5. 인증 세션 타임아웃 🔴

- 지금: 지오펜스 exit을 못 받으면 `ended_at`이 영원히 null로 남는다.
  `certifications_one_active_idx`(사용자당 진행 중 1건) 때문에 **다음 인증이 아예 안 된다**
- 필요: pg_cron으로 N시간 이상 된 세션 자동 종료

#### 6. 주차면 홀드 만료 처리 🔴

- 지금: `parking_holds.hold_to`가 지나도 `parking_spots.available`이 복구되지 않는다.
  예약할 때마다 자리가 하나씩 영구히 잠긴다
- 필요: pg_cron으로 만료된 홀드 해제 + available 복구

### B. 운영에 필요한 것

#### 7. 예약 슬롯 자동 생성

시드로 7일치만 넣었다. **8일 뒤부터 예약할 슬롯이 없다.** 시설별 운영시간을 받아
슬롯을 굴려 생성하는 잡이 필요하다.

#### 8. 혜택 데이터 수집·갱신

혜택 6건이 시드로 하드코딩돼 있다. 복지로·지자체 공고를 수집하고,
마감 지난 혜택을 자동 비활성화하는 파이프라인이 필요하다.
`eligibility` 규칙(jsonb)은 사람이 관리해야 하므로 관리 화면도 함께.

#### 9. FCM 푸시

`devices` 테이블만 있고 **토큰 등록·발송 경로가 없다.** 지금은 로컬 알림뿐이라
앱이 꺼져 있으면 아무것도 못 알린다.

- 혜택 마감 임박 · 새 맞춤 혜택
- 예약 하루 전 리마인더
- 신고 처리 결과
- 주차면 빈자리 알림 (지도 화면의 "빈자리 알림 받기"가 현재 스낵바만 띄운다)

#### 10. 신고 처리 워크플로

접수만 되고 그 뒤가 없다. 담당 지자체 전달, 상태 전이(`reviewing`→`confirmed`),
결과 통보, 그리고 확인된 신고로 `warnings` 자동 생성.

#### 11. 관리자 화면

주차면 등록·수정, 혜택 관리, 신고 처리 큐, 사용자 자격 심사.

### C. 품질 · 보안

#### 12. Edge Function 배포

`naver-auth`(네이버 로그인용)와 `certify-parking`은 코드만 있고 배포되지 않았다.
배포에는 Management API 토큰(`npx supabase login`)이 필요하다.
현재 인증 진행은 DB 트리거가 대신하고 있다 — 연동이 확정되면 트리거를 지우고 되돌린다
(외부 HTTP 호출을 트리거 안에서 하면 INSERT를 붙잡고 있게 된다).

#### 13. 개인정보 보존·파기 정책

신고 사진의 보존 기간과 자동 삭제, 인증 이력 보존 기간. 위치 이력은 저장하지 않는다.

#### 14. 모니터링

Edge Function 로그·에러 추적, 인증 실패율, 지오펜스 발화율.

## 접근성

장애인 대상 앱이므로 요건이다.

- 모든 탭 가능 요소 최소 44dp, 주 CTA 50–56dp
- 아이콘·이모지 버튼에 `Semantics(label:)` — 스크린리더로 전 화면 완주 가능
- 글자 크기 확대(최대 1.6배) 존중 — 고정 높이 대신 `minHeight`
- 색만으로 상태를 구분하지 않음 (인증/미인증에 ✓·! 병기)
- 인증 완료 시 스크린리더 안내 + 햅틱
- `MediaQuery.disableAnimations`를 켜면 깜빡임·부유 애니메이션이 멈춘다
- 1km 넘는 거리는 "도보"가 아니라 "차량"으로 안내 (보행상 장애 고려)

**아직 안 한 것:** 실제 스크린리더(TalkBack·VoiceOver)로 전 화면을 훑는 감사.

## 프로토타입과 의도적으로 다른 점

| 프로토타입 | 구현 | 이유 |
|---|---|---|
| 아바타 이니셜 `SH` | 이름 뒤 두 글자 (`형수`) | 한글 이름에서 로마자 이니셜을 만들 수 없다 |
| 완료 히어로 "2시간 12분 남음" | "단속 대상 제외" | 무료 주차 시간 정책이 데이터에 없다 |
| 로그인 화면 없음 | 로그인 화면 신설 | 소셜 로그인 요구사항 |
| 인증 3단계 3.9초 | 실제로는 즉시 완료 | 그 3.9초는 연출용 sleep이었다. 외부 호출이 없으면 즉시 끝나는 게 맞다 |

## 알려진 문제

- **목업 지도의 핀이 겹친다** — 좌표 투영은 맞지만 잔여면 라벨이 포개진다.
  실제 지도 SDK는 마커 충돌을 처리하므로 목업에서는 그대로 둔다
- 릴리스 fat APK 126MB — split/AAB로 해결 (네이버 지도 SDK가 ABI당 18~25MB)
- 지도 API는 **유료다.** 네이버·카카오 모두 무료 정책이 축소됐다. [docs/SETUP.md](docs/SETUP.md#3-a-지도--️-유료다-서두르지-말-것) 참고
